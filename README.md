# projetoCG
Compoutação Gráfica


## como usar (mac e linux porque windows ninguém sabe)


na pasta phase1 fazer
```
cmake -S . -B outputs
```

na pasta outputs fazer
```
make
```

depois

```
./generator <figura> <tamanhos> <nomeficheiro.3d>
```

ou

```
./engine ../test_files/test_files_phase_1/<teste>
```
